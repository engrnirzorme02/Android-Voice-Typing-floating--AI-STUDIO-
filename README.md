# 🎙️ Voice Bubble - Floating Voice Typing with AI Studio

**Voice Bubble** একটি অত্যাধুনিক Android অ্যাপ্লিকেশন যা ফ্লোটিং বাবলের মাধ্যমে রিয়েল-টাইম ভয়েস টাইপিং অনুমতি দেয়। এটি স্বয়ংক্রিয়ভাবে আপনার কণ্ঠস্বর রেকর্ড করে, এটি স্বয়ংক্রিয়ভাবে ক্লিপবোর্ডে কপি করে এবং SwiftKey বা যেকোনো কীবোর্ডে তাত্ক্ষণিক পেস্ট করার জন্য প্রস্তুত থাকে। Google Gemini AI দ্বারা চালিত, এটি ব্যাকরণ এবং ফিলার শব্দ স্বয়ংক্রিয়ভাবে পরিষ্কার করে উচ্চমানের টেক্সট সরবরাহ করে।

## 🌟 মূল বৈশিষ্ট্য (Key Features)

### 🎯 ভয়েস রেকর্ডিং এবং ট্রান্সক্রিপশন
- **রিয়েল-টাইম রেকর্ডিং**: ফ্লোটিং বাবলে ট্যাপ করুন এবং তাত্ক্ষণিকভাবে কথা বলা শুরু করুন
- **মাল্টি-ল্যাঙ্গুয়েজ সাপোর্ট**: বাংলা (বাংলাদেশ/ভারত), ইংরেজি (US/UK), হিন্দি, আরবি, স্প্যানিশ, ফ্রেঞ্চ সহ ৮টিরও বেশি ভাষা সমর্থন করে
- **অফলাইন মোড**: সম্পূর্ণ অফলাইনে স্থানীয় ভয়েস রেকগনিশন
- **সিস্টেম ডিফল্ট ভাষা**: স্বয়ংক্রিয়ভাবে সিস্টেম সেটিংস থেকে ভাষা নির্ণয় করে

### ✨ AI-চালিত স্মার্ট পরিস্কারণ
- **Gemini AI ইন্টিগ্রেশন**: Google's Gemini 2.5 Flash মডেলের সাথে একীভূত
- **স্বয়ংক্রিয় পুনর্লিখন**: ব্যাকরণগত ত্রুটি সংশোধন এবং ফিলার শব্দ অপসারণ
- **প্রাকৃতিক ভাষা পলিশিং**: কথ্য বাংলা থেকে লিখিত বাংলায় রূপান্তর
- **টগল সুবিধা**: দ্রুত মেনু থেকে AI পলিশিং সক্ষম/নিষ্ক্রিয় করুন

### 📋 ক্লিপবোর্ড ম্যানেজমেন্ট
- **স্বয়ংক্রিয় কপি**: ট্রান্সক্রিপশন সম্পন্ন হওয়ার সাথে সাথে ক্লিপবোর্ডে কপি হয়
- **ওয়ান-ট্যাপ পেস্টিং**: যেকোনো অ্যাপ্লিকেশন বা কীবোর্ডে তাৎক্ষণিক পেস্ট করুন
- **হিস্ট্রি ট্র্যাকিং**: সমস্ত ভয়েস রেকর্ডিং এবং ট্রান্সক্রিপশনের ইতিহাস বজায় রাখে
- **সম্পাদনা এবং পুনঃ-ব্যবহার**: পূর্ববর্তী রেকর্ডিং সম্পাদনা করুন এবং পুনরায় কপি করুন

### 🎨 কাস্টমাইজেশন অপশন
- **বাবল সাইজ নিয়ন্ত্রণ**: ৪০ ডিপি থেকে ১০০ ডিপি পর্যন্ত সামঞ্জস্য করুন
- **স্বচ্ছতা সেটিংস**: বাবলের অপ্যাসিটি সম্পূর্ণ নিয়ন্ত্রণ করুন (0-100%)
- **পজিশন সংরক্ষণ**: স্ক্রিনে বাবলের অবস্থান স্বয়ংক্রিয়ভাবে মনে রাখে
- **এজ ডকিং**: বাবল স্বয়ংক্রিয়ভাবে স্ক্রিন প্রান্তে লুকিয়ে যায়

### 🎯 স্বজ্ঞাত ব্যবহারকারী ইন্টারফেস
- **হোম স্ক্রিন**: সার্ভিস স্ট্যাটাস এবং দ্রুত অ্যাক্সেস নিয়ন্ত্রণ
- **হিস্ট্রি স্ক্রিন**: সমস্ত পূর্ববর্তী ভয়েস রেকর্ডিং ব্রাউজ করুন এবং অনুসন্ধান করুন
- **সেটিংস স্ক্রিন**: ভাষা, বাবল চেহারা এবং AI বৈশিষ্ট্যগুলি সূক্ষ্ম সামঞ্জস্য করুন
- **বাংলা ভাষা ইন্টারফেস**: সম্পূর্ণ বাংলা স্থানীয়করণ সহ

### 🔔 ফিডব্যাক এবং ইঙ্গিত
- **ভাইব্রেশন ফিডব্যাক**: রেকর্ডিং শুরু/শেষে ট্যাকটাইল প্রতিক্রিয়া
- **সাউন্ড ফিডব্যাক**: শ্রবণগত নিশ্চিতকরণ টোন
- **ভিজ্যুয়াল ইঙ্গিত**: পালস অ্যানিমেশন এবং স্ট্যাটাস ব্যাজ

### ⚙️ উন্নত বৈশিষ্ট্য
- **কুইক মেনু**: দীর্ঘ-চাপ করে দ্রুত অ্যাক্সেস এবং কাস্টমাইজেশন
- **স্বয়ংক্রিয় ডিম**: নিষ্ক্রিয়তার সময় বাবল অপ্যাসিটি হ্রাস করে
- **ভাষা ব্যাজ**: বর্তমান সনাক্তকৃত ভাষা দেখানোর জন্য বাবলে ফ্ল্যাগ ডিসপ্লে
- **পারমিশন ম্যানেজমেন্ট**: ওভারলে, মাইক এবং বিজ্ঞপ্তি পারমিশন স্বয়ংক্রিয় অনুরোধ

## 🛠️ প্রযুক্তিগত স্ট্যাক (Tech Stack)

### প্রোগ্রামিং ভাষা
- **প্রাথমিক**: Kotlin
- **অতিরিক্ত**: Java (Android SDK), XML (রিসোর্স)

### ফ্রেমওয়ার্ক এবং লাইব্রেরি

#### UI এবং Compose
- **Jetpack Compose**: আধুনিক ডিক্লেরেটিভ UI তৈরির জন্য
- **Compose Material 3**: ডিজাইন সিস্টেম এবং থিম
- **Compose Navigation**: মাল্টি-স্ক্রিন নেভিগেশন

#### ডাটা স্টোরেজ
- **Room Database**: লোকাল সিকোয়েল ডাটাবেস (হিস্ট্রি সংরক্ষণের জন্য)
- **SharedPreferences**: অ্যাপ্লিকেশন সেটিংস পার্সিস্টেন্স

#### নেটওয়ার্কিং এবং API
- **Retrofit**: REST API ক্লায়েন্ট (Gemini API-এর জন্য)
- **OkHttp**: HTTP ক্লায়েন্ট উন্নত কনফিগারেশন সহ
- **Moshi**: JSON সিরিয়ালাইজেশন/ডিসেরিয়ালাইজেশন

#### ভয়েস প্রসেসিং
- **Android Speech Recognition**: SpeechRecognizer API
- **Google Gemini AI**: প্রাকৃতিক ভাষা প্রক্রিয়াকরণ এবং পলিশিং

#### অ্যাসিঙ্ক্রোনাস প্রোগ্রামিং
- **Kotlin Coroutines**: অ-ব্লকিং অপারেশন এবং UI আপডেট
- **Flow & StateFlow**: রিঅ্যাক্টিভ ডেটা প্রবাহ

#### অন্যান্য টুলস
- **Firebase**: অ্যাপ ইন্টিগ্রেশন এবং নিরাপত্তা (App Check)
- **KSP (Kotlin Symbol Processing)**: Compile-time কোড জেনারেশন
- **Gradle**: প্রজেক্ট বিল্ড এবং নির্ভরতা ম্যানেজমেন্ট

## 🔄 কীভাবে কাজ করে (How It Works)

### 1️⃣ **রেকর্ডিং ফ্লো**
```
ব্যবহারকারী ট্যাপ করে
    ↓
FloatingBubbleService ঘটনা ক্যাপচার করে
    ↓
SpeechEngine স্টার্ট রেকর্ডিং
    ↓
অডিও প্রসেসিং এবং ট্রান্সক্রিপশন
    ↓
ট্রান্সক্রাইব করা টেক্সট প্রাপ্ত
```

### 2️⃣ **AI পলিশিং ফ্লো** (যখন সক্ষম থাকে)
```
ট্রান্সক্রাইব করা টেক্সট
    ↓
Gemini API-তে পাঠান
    ↓
"পলিশিং" প্রম্পটের সাথে প্রক্রিয়াকরণ
    ↓
সংশোধিত, পরিষ্কার টেক্সট ফেরত পান
```

### 3️⃣ **ক্লিপবোর্ড এবং হিস্ট্রি ফ্লো**
```
চূড়ান্ত টেক্সট
    ↓
ক্লিপবোর্ডে কপি করুন
    ↓
Room ডাটাবেসে সংরক্ষণ করুন
    ↓
"কপি হয়েছে ✓" ব্যাজ প্রদর্শন করুন
    ↓
যেকোনো অ্যাপে পেস্ট করুন
```

### 4️⃣ **নেভিগেশন এবং UI**
```
MainActivity (তিন-ট্যাব নেভিগেশন)
│
├─→ HomeScreen (স্টার্ট/স্টপ সার্ভিস, পারমিশন ম্যানেজমেন্ট)
├─→ HistoryScreen (পূর্ববর্তী রেকর্ডিং ব্রাউজ এবং সম্পাদনা)
└─→ SettingsScreen (ভাষা, বাবল সেটিংস, AI বৈশিষ্ট্য কনফিগার)
```

## 🚀 চালু করা এবং কনফিগারেশন (Getting Started)

### ১. প্রয়োজনীয়তা
- **Android Studio** (Jellyfish বা নতুনতর)
- **Kotlin** (১.৯+)
- **Java** (১১+)
- **Gradle** (৮.+)

### ২. রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/engrnirzorme02/Android-Voice-Typing-floating--AI-STUDIO-.git
cd Android-Voice-Typing-floating--AI-STUDIO-
```

### ৩. Gemini API কী সেটআপ করুন

**`.env` ফাইল তৈরি করুন** (``.env.example` থেকে কপি করুন):
```bash
cp .env.example .env
```

**আপনার Gemini API কী যোগ করুন:**
```dotenv
GEMINI_API_KEY=আপনার_GEMINI_API_কী_এখানে
```

> 📌 **API কী পান**: [Google AI Studio](https://aistudio.google.com/app/apikey) থেকে বিনামূল্যে API কী তৈরি করুন

### ৪. প্রজেক্ট তৈরি করুন এবং চালান

**Android Studio-তে:**
1. ফাইল → খোলা → রিপোজিটরি নির্বাচন করুন
2. `Build` → `Rebuild Project` ক্লিক করুন
3. একটি ডিভাইস বা এমুলেটর সংযুক্ত করুন
4. `Run` → `Run 'app'` ক্লিক করুন

**কমান্ড লাইন থেকে:**
```bash
./gradlew build
./gradlew installDebug
```

### ৫. প্রথম চালু করার পরে
- অ্যাপ খুলুন
- হোম স্ক্রিনে প্রয়োজনীয় সমস্ত অনুমতি প্রদান করুন:
  - ✅ Overlay পারমিশন
  - ✅ মাইক্রোফোন অ্যাক্সেস
  - ✅ নোটিফিকেশন অনুমতি
- "সার্ভিস সক্রিয় করুন" বোতামে ট্যাপ করুন
- ফ্লোটিং বাবল প্রদর্শিত হবে!
